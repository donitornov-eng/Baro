# Global Overhaul — development environment

Foundation for a global Barotrauma overhaul (XML content + in-memory C# via LuaCs).

## Installed pieces

| Piece | Location | Version |
|---|---|---|
| Barotrauma | `D:\Steam\steamapps\common\Barotrauma` | 1.13.5.0 |
| LuaCsForBarotrauma (workshop `2559634234`) | `...\workshop\content\602960\2559634234` | 1.0.117 |
| This package (live junction) | `<game>\LocalMods\GlobalOverhaul` → `G:\OpenCode\BOGM` | 0.1.0 |
| Decompiled reference | `_ref/` (game + LuaCs) | regenerated by `tools/refresh-ref.ps1` |

The game reads this folder directly through a directory junction, so there is no
build or copy step. LuaCs compiles `CSharp/Shared/*.cs` in memory at load time.

## Tools

```powershell
pwsh tools/deploy.ps1              # (re)create the LocalMods junction
pwsh tools/deploy.ps1 -Remove      # unlink
pwsh tools/refresh-ref.ps1 -Force  # re-decompile after a game/LuaCs update
```

## MCP

`opencode.json` configures the GitHub MCP server (code search for LuaCs sources,
vanilla content and other mods). The endpoint does not offer OAuth to this client,
so it authenticates with a token from the `GITHUB_TOKEN` environment variable:

```powershell
[Environment]::SetEnvironmentVariable('GITHUB_TOKEN', '<token>', 'User')
```

Restart OpenCode afterwards so the process inherits the variable, then check
`/mcps`. Token: classic PAT with `public_repo` (add `repo` for private repos),
or fine-grained with `Contents: read` + `Metadata: read`.

## Packaging note

`_ref/` (25 MB of decompiled sources) and `.opencode/` are development-only.
Exclude both if this folder is ever zipped or uploaded to the Workshop.
