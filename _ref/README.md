## Rules of thumb

- Signatures, default values and method bodies: read `project/`.
- Anything under `Barotrauma.LuaCs` (`IAssemblyPlugin`, `IConfigService`,
  `PluginManagementService`, `SettingsFileParserService`, ...): read `luacs/`.
- LuaCs ships *publicized* reference assemblies from 1.13.4. They are what the
  in-memory compiler resolves against, so a member added in 1.13.5 may decompile
  fine in `project/` but fail to compile. If that happens, use reflection
  (`AccessTools`/`Type.GetMethod`) instead of a direct call.
- Decompiled output is for reading, never for copying into `CSharp/`.

## Fast lookups

```powershell
# where is a type declared?
Select-String -Path _ref/index.txt -Pattern 'StoreInfo'

# every place a member is used in the game
Select-String -Path _ref/project/**/*.cs -Pattern 'CreateStock'
```

`_ref/index.txt` is a `TypeName<TAB>relative\path.cs` map built from the
decompiled tree.
